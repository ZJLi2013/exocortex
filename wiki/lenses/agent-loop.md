# agent-loop

## 范围

会改变 agent-loop 探索模式、评估 / 预算 / 人工介入设计的 research agent 与自改进系统。

## 问题

### Q1 接纳候选靠什么评估？
当前答案：评估协议固定且 agent 改不了；选出与确认用不同集合；不用 LLM 打分当接纳信号。依据 C1、C2、C3

### Q2 什么时候做搜索或自改进，下一个实验怎么选？
当前答案：没有程序化评估器就不做进化搜索；本库没有固定 benchmark，不做自改进；预算有限时按信息增益与实验成本之比选下一个实验。依据 C4、C5、C6、C7

### Q3 人什么时候介入、预算怎么计？
当前答案：子任务末设人工检查点能提高外部评审分，但研究者难以按自己的构想引导；预算按服务计费（RSIGym 每次 \$500），还没有比较不同预算机制的证据。依据 C8

## 判断

### C1 评估协议固定、agent 改不了时，research agent 多数能超过初始系统
- 回答：Q1
- 支持：
  - [[rsigym]]（自报）30 个 Joint run 有 29 个超过初始系统；任务定义规定评估协议与事后审计
  - [[alphaevolve]]（自报）评估函数由用户写；Borg 调度部署后持续回收 0.7% 算力，Gemini kernel 提速 23%
- 限定：
  - [[rsigym]]（自报）final evaluation 复用开发期可见的任务；每个配置只跑一次
- 反驳：—
- 推翻：评估协议固定、agent 改不了的设定下，多数 run 没有超过初始系统

### C2 用独立确认集选出的候选，部署或测试集结果与选出时一致
- 回答：Q1
- 支持：
  - [[alphaevolve]]（自报）Borg 在历史快照上选出、未见近期负载上确认，部署实测与模拟一致；kernel 输入形状一半训练一半评估
  - [[agent-laboratory]]（自报）MLE-Bench 在 20% dev 集上选程序，Kaggle 测试集确认，10 题 4 枚奖牌
- 限定：—
- 反驳：—
- 推翻：用独立确认集选出的候选，部署或测试集结果明显差于选出时

### C3 LLM 评审明显高估研究产出质量
- 回答：Q1
- 支持：
  - [[agent-laboratory]]（自报）自动评审总分 6.1，人评 3.8；LLM 与人评一致率 53.3%，人与人 56.1%
  - [[rsiagent]]（自报）verifier 在官方 rubric 下仍有错时返回 PASS
- 限定：—
- 反驳：—
- 推翻：LLM 评审与人评的差距缩到人与人一致率以内

### C4 在小开发集上自选候选的自改进，没有迁移到全集
- 回答：Q2
- 支持：
  - [[rsigym]]（自报）Qwen3.8-27B 自改进，6 题开发集上的增益没有迁移，SkillsBench 全集 56.66% → 56.26%
- 限定：
  - [[rsiagent]]（自报）选出与确认在同一目标任务上，OSWorld 2.0 71.97 → 78.98；只有部分题有 RSI 结果
- 反驳：—
- 推翻：小开发集上自选的自改进在全集上显著提升

### C5 权重固定、benchmark 固定时，外部 agent 改 harness 能涨分
- 回答：Q2
- 支持：
  - [[rsigym]]（自报）Opus 5 改 DSH，Terminal-Bench 30.34% → 40.82%，三次全对的任务 15 → 26
- 限定：—
- 反驳：—
- 推翻：权重与 benchmark 同样固定，改 harness 没有涨分

### C6 进化式代码搜索只在有程序化评估器的问题上有效
- 回答：Q2
- 支持：
  - [[alphaevolve]]（自报）作者称只适用于能写出自动评估器的问题；去掉进化的消融明显变差
- 限定：—
- 反驳：—
- 推翻：没有自动评估器（如只用 LLM 打分）的进化搜索取得同等结果

### C7 预算有限时，按信息增益与实验成本之比选实验，比随机探索有效
- 回答：Q2
- 支持：
  - [[embodiedrsi]]（自报）50 个物理 episode 后 72.9% 对随机探索 27.1%，learning AUC 0.635 对 0.309
- 限定：—
- 反驳：—
- 推翻：同预算下随机或均匀探索追平

### C8 子任务末设人工检查点能提高外部评审分，但研究者难以引导 agent 按自己的构想执行
- 回答：Q3
- 支持：
  - [[agent-laboratory]]（自报）co-pilot 模式外部评审 4.38，比自主模式高 0.58；研究者自评实验质量 2.38，低于自主模式
- 限定：—
- 反驳：—
- 推翻：同后端、同评审下，逐子任务检查点的外部评审分不高于自主模式
