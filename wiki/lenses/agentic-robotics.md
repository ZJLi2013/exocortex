# agentic-robotics

## 范围

会改变 RoboRSI 选底座、改进方向或评测选择的 agent × 机器人工作。

## 问题

### Q1 选什么当 agent 底座？
当前答案：冻结的前沿 LLM 当 coding agent；GPT-6 Astra 在唯一一组横比里领先，证据只有一组，未定型。依据 C1

### Q2 改进方向先改什么？
当前答案：先改模型外的代码技能与记忆，行为稳定后编译成脱离 agent 的程序；通用多模态基座用来搭仿真、定义任务和造数据。依据 C2、C3、C4

### Q3 评测用什么、要覆盖什么？
当前答案：不用 LIBERO-Pro 整体平均比较 code-as-policy 方法，要看扰动子集；评测要覆盖主动取证与何时提交；世界模型评测暂不替代真机；演化与报告用互不相交的集合。依据 C5、C6、C7、C8

## 判断

### C1 需要交互取证的移动操作上，GPT-6 Astra 领先其余前沿模型，且它产出的技能能迁到其他模型
- 回答：Q1
- 支持：
  - [[roboquest]]（自报）每格 50 episode：Astra 23.2%，次高 Opus 5.5 13.8%
  - [[embodiedevo]]（自报）Astra 的 Skills / Lessons 让 Sol、Luna 成功率各升 8.86、5.50 个百分点
- 限定：—
- 反驳：—
- 推翻：同一协议的另一组横比里其他模型领先

### C2 冻结模型、只改模型外的代码技能与记忆，能在未见场景大幅提高成功率
- 回答：Q2
- 支持：
  - [[embodiedevo]]（自报）只给任务描述 8.50% → 30.17%，Test 布局与 Playground 不同
  - [[rax]]（自报）未见布局平均成功率 25% → 79%（探索 4 → 128 回合）
  - [[embodiedrsi]]（自报）RoboCasa365 Composite-Unseen 71.3%，Harness VLA 40.1%；真机 SmolVLA 46.0% → 71.3%
  - [[aspire]]（自报）技能库零样本用到未见长程任务 31%，已有方法 4%
- 限定：
  - [[embodiedevo]]（自报）精细插入与液体操作仍难
  - [[aspire]]（自报）依赖冻结前沿 LLM 与固定的感知 / 规划 / 控制原语 API
- 反驳：—
- 推翻：同样冻结模型、同样在未见场景评测，只改模型外的代码技能与记忆没有提升

### C3 agent 探索出的行为能编译成脱离 agent 运行的程序，执行快两个数量级
- 回答：Q2
- 支持：
  - [[rax]]（自报）Air fryer 72 min → 18 s（241×），Bandu tower 17 min → 10 s（103×）
- 限定：—
- 反驳：—
- 推翻：编译后的程序执行时间与 agent 本身相当

### C4 通用多模态基座能替人搭仿真、定义任务、造数据，并提高真机成功率
- 回答：Q2
- 支持：
  - [[gemini-4-argon]]（自报）一张照片建 MuJoCo 孪生、定义 77 个任务、生成 4,500+ 条轨迹，真机 56% → 75%（未给评测次数）
- 限定：—
- 反驳：—
- 推翻：给出评测次数后提升消失，或流程仍需人补任务定义

### C5 code-as-policy 加 Claude Opus 5.5 在 LIBERO-Pro 上整体平均已到 99%
- 回答：Q3
- 支持：
  - [[aspire]]（自报）全部任务平均 99%，held-out seed 每任务 50 个
- 限定：
  - [[embodiedrsi]]（自报）冻结 VLA 加 harness 的设定下，T / S 扰动 8 格上 86.8% 对 Harness VLA 72.1%，扰动子集仍能拉开差距
- 反驳：—
- 推翻：同设定下复现的整体平均明显低于 99%

### C6 需要交互取证的任务上，前沿模型整体成功率很低，失败主因是缺证据而不是执行
- 回答：Q3
- 支持：
  - [[roboquest]]（自报）整体最高 23.2%；失败归因缺证据 43–46%，执行 18–21%
- 限定：
  - [[roboquest]]（自报）执行技能单测 72–81% 是在给出隐藏信息的条件下测的，与整体评测条件不同
- 反驳：—
- 推翻：不给隐藏信息的执行单测下，执行失败成为主因

### C7 动作条件世界模型能在想象中闭环评测 VLA 的指令遵循，但与真机的一致性没有数字
- 回答：Q3
- 支持：
  - [[ctrl-world]]（自报）README 未给世界模型评测与真机结果的一致性；作者称物理交互建模可能不准
- 限定：—
- 反驳：—
- 推翻：给出世界模型评测与真机成功率的一致性数字且一致性高

### C8 报告未见场景提升的工作，演化用的集合与报告用的集合都互不相交
- 回答：Q3
- 支持：
  - [[embodiedevo]]（自报）Playground 与 Test 布局不同；Test 只读、不能 reset、不回写经验
  - [[rax]]（自报）正式评测用 held-out layouts，冻结程序在从未见过的布局上运行
  - [[embodiedrsi]]（自报）10 个 seed 演化，另 10 个互不相交的 seed 评测
  - [[aspire]]（自报）debug split 上学习，互不相交的 held-out seed 上报告
- 限定：
  - [[embodiedrsi]]（自报）成功判定器由谁实现未说明
  - [[aspire]]（自报）成功由谁判定未说明
- 反驳：—
- 推翻：出现演化与报告用同一集合、却报告未见场景提升的工作
