# SGS

PPO 外加一层按成功率加权的任务配置采样（Success-Guided Sampling），只改环境 reset 到哪个配置；并行环境扩到 100 万时 ANYmal D 全地形成功率 0.73、Franka 螺母装配 0.70，均匀采样两项都约为 0。

- **关键数字**（三 seed 均值 ± 95% CI，4K / 32K / 256K / 1M 并行环境）：
  - ANYmal D 全地形：SGS 0.46 / 0.49 / 0.72 / 0.73；PLR 0.00 / 0.13 / 0.55 / 0.54；Uniform 0.00 / 0.42 / 0.00 / 0.00；线性课程 0.00 / 0.32 / 0.00 / 0.00。
  - Franka 螺母螺栓：SGS 0.00 / 0.06 / 0.10 / 0.70；1M 时 PLR 0.05、Uniform 0.06。
  - 单个固定配置（UR5e 螺母，每 checkpoint 64 次）：迭代 2,800 前 0/64，4,200 时 51/64，5,400 时 59/64；SGS 权重随之先升后降。
  - 真机 UR5e 只在仿真训练、RGB 输入零样本装配螺母、杆、齿轮；真机成功率未给。
- **评估与接纳**：
  - 训练前固定采样 N 个任务配置 (s0, g, e)；成功率是在这些配置上还是另取的配置上测，未说明。
  - 装配任务零示教、所有任务同一奖励函数；成功判定器未说明。
  - 真机由谁判成功、试验次数未说明。
- **可信度**：CoRL 2026 项目页，作者自报；三 seed；代码标为 coming soon，未开源。
