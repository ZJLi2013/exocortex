# 经验写成代码技能

agent 把交互中学到的东西固化成可执行、可复用的代码或技能条目，而不是更新权重。

## 来源
- [[embodiedevo]]：物理反馈蒸馏成代码 Skills 与诊断 Lessons，Test 执行成本低 53.0%。
- [[embodiedrsi]]：代码与技能联合演化，挂在 Hypothesis Graph 上。
- [[aspire]]：验证过的修复存进技能库。
- [[rax]]：skill 需两次无人值守成功才标 `verified`；最终编译成脱离 agent 的程序。
- [[rsiagent]]：verifier 判 PASS 的经验才写入 memory；未验证的决定被写成规则是其失败模式。
