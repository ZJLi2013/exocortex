# 自改进

系统根据自己的执行反馈修改自己（数据、代码、harness 或权重）。

## 来源
- [[rsigym]]：研究 agent 改进目标系统；研究者与目标是同一模型时（Qwen3.8-27B）全集不涨。
- [[embodiedevo]]：self-evolving coding agent，经验写成 Skills / Lessons，不更新权重。
- [[gemini-4-argon]]：SO-101 上按日志与录像自诊断、干跑验证后重试，三轮 58.9 s → 17.4 s。
- [[alphaevolve]]：优化 Gemini 训练 kernel（训练时间减 1%），但改进下一版 AlphaEvolve 的反馈环以月计、增益温和。
- [[embodiedrsi]]：Hypothesis Graph 驱动的代码 / 技能自演化。
- [[aspire]]：验证过的修复进技能库，零样本用到未见长程任务 31% vs 4%。
- [[rax]]：在线探索 4 → 128 回合，未见场景 25% → 79%。
- [[rsiagent]]：先广后深地自主练习；只 DRS 在两题上低于 baseline。
