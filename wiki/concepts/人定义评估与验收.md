# 人定义评估与验收

human 写定任务、评估协议或验收阶段，agent 只在这个框内搜索与改进，不能改评判它的东西。

## 来源
- [[rsigym]]：`instruction.md` 与 `key.json` 规定可改部分、提交物、评估协议、预算与事后审计。
- [[embodiedevo]]：协议文件与执行记录对 agent 只读；Test 阶段不能 reset。
- [[gemini-4-argon]]：硬件自改进的三个阶段与安全规则由人写，提速超过 2× 要人授权。
- [[alphaevolve]]：评估函数由用户写，只适用于能写出自动评估器的问题。
- [[autoresearch]]：评估写死在人写的 `prepare.py`，agent 只改 `train.py`。
- [[embodiedrsi]]：VLA 冻结；成功用 benchmark 二值结果，消融时评估协议固定。
- [[aspire]]：换模型对比时环境、原语 API 与评估协议固定。
- [[rax]]：操作员 arm / disarm 目录 agent 不可写，recorder 只读。
- [[roboquest]]：成功由 benchmark 规则在 SUBMIT 时判定，隐藏信息 agent 读不到。
- [[rsiagent]]：官方评估器在所有循环之后调用，不回传分数。
- [[agent-laboratory]]：流程内由 LLM 评审接纳，最终质量靠人评；自动评审比人评高约 2.3 分。
