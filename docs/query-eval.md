# 查询评测

**5 道跨来源检索题，测无上下文 agent 按 `AGENTS.md`「查询」一节能否找全事实。** 用于结构改动后的回归，或比较不同模型够不够用。

## 怎么跑

每个模型开一个新会话，只读仓库，只按 `AGENTS.md`「查询」一节作答；每题一个 `## Q<n>` 小节，≤ 8 行，必须引用 `wiki/` 路径。
答案存成文件后运行 `python scripts/check_answers.py <答案文件>`，按关键词评分，5 题过 4 题算通过。

## 题目

| 题 | 问题 |
|---|---|
| Q1 | 哪些工作把「选出候选的集合」和「确认胜出的集合」分开？ |
| Q2 | Gemini 4 Argon 的公开状态和已知读数是什么？ |
| Q3 | 哪些系统由 human 写评估器、任务定义或验收，agent 只在其内搜索？ |
| Q4 | 收录的来源里，哪些是 2026-10 发布的？ |
| Q5 | 哪些地方记录了自改进没有迁移，或自动评估高估了结果？ |

关键词金标准在 `scripts/check_answers.py`，跟随 `wiki/sources/` 的事实更新。
